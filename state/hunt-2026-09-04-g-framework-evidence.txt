 A posição tem como objetivo técnico de reescrever completamente um site institucional/comercial de alto tráfego para React, garantindo que a migração preserve e idealmente melhore o desempenho, o posicionamento em mecanismos de busca tradicionais (SEO) e a visibilidade em motores de busca generativos baseados em IA (GEO/AEO), como ChatGPT, Perplexity e AI Overviews do Google. 
 O que é preciso para fazer parte do time?
Experiência com React em produção, incluindo domínio de frameworks com renderização no servidor (Next.js)
Conhecimento aprofundado de estratégias de renderização SSR, SSG, ISR e/ou React Server Components com capacidade de escolher a abordagem certa para cada tipo de página.
Domínio de performance web e Core Web Vitals (LCP, INP, CLS): profiling, otimização de imagens, code splitting, controle de script budget e diagnóstico de regressões.
Experiência prática com SEO técnico aplicado a aplicações React/JS: meta tags dinâmicas, canonical URLs, sitemap.xml, robots.txt, dados estruturados (JSON-LD/schema.org) e hreflang.
Conhecimento de GEO/AEO (Generative Engine Optimization / Answer Engine Optimization): estruturação de conteúdo para ser compreendido e citado por IAs generativas, arquivos de descoberta como llms.txt e configuração correta de acesso para bots de IA (GPTBot, ClaudeBot, PerplexityBot).
Arquitetura front-end sênior: BFF (Backend for Frontend), caching layers, streaming e definição clara da fronteira entre client e server.
Capacidade de consumir e integrar APIs de um backend em .NET, incluindo entendimento de como os dados fluem entre sistemas (ex.: eventos via RabbitMQ/Kafka) para depurar problemas de ponta a ponta.
Conforto trabalhando em ambiente containerizado com Docker para desenvolvimento local e integração com os serviços do time de backend.
Uso fluente de ferramentas de IA para codificação (GitHub Copilot, Cursor, Claude ou similares) como parte natural do fluxo de trabalho diário, não como recurso pontual.
TypeScript, testes automatizados (unitários e de integração) e boas práticas de componentização e reuso.
Autonomia e visão de produto para conduzir tecnicamente uma reescrita de site de ponta a ponta, sem perda de ranqueamento orgânico nem degradação de performance durante a migração.
